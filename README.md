# Elevprojektssystem

Ett fullstack-system där lärare kan registrera elever och hantera deras projekt, status och deadlines.

## Tech-stack

- React och TypeScript
- Node.js och Express
- PostgreSQL och SQL
- REST API
- Docker Compose
- Git och GitHub
- Kanban/Scrum

## Projektstruktur

- `client` – frontend
- `server` – backend och REST API
- `database` – SQL-filer
